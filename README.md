# Алексей — дизайн, 3D и разработка

Сайт-визитка с интерактивной 3D-сценой, перечнем услуг и подборкой работ.

[Открыть сайт](https://alexden09-boop.github.io/alexey-portfolio/) · [Перейти в 3D-сцену](https://alexden09-boop.github.io/alexey-portfolio/3d/index.html)

## Локальный запуск

Из корневой папки выполните команды с установленным Node.js 22 или новее.

```sh
npm ci
npm run build
npm start
```

Откройте [локальную версию](http://127.0.0.1:4320/). Для проверки интерфейса при запущенном сервере выполните `npx playwright install chromium` и `npm run check`.

## Обновление сайта

Основная разметка находится в `index.html` и `hero.html`, анимация — в `main.js`, `scene.js` и `documents.js`. Интерактивная ледяная сцена находится в папке `3d/`. Контакты и подборка работ задаются в `content.js`.

GitHub Pages публикует папку `docs/` из ветки `main`. После правок выполните `npm run build`, затем добавьте в коммит обновлённые исходники и `docs/` и отправьте изменения в `main`.
